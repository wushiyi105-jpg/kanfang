# UI 说明：看房

- **谁在什么时刻打开**：给近期要签租约的人。
- **首屏任务句**：这两套房，首月各要备多少。
- **主操作**：按「贴两段房源 → 拆五项成本 → 带走看房问题单」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：两份摊开的房源档案；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：两份摊开的房源档案。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给近期要签租约的人：贴两段房源介绍，把押金、服务费、物业和一次性成本拆开。改租期，首月现金和摊到每月一起变。
