# examples

四份脱敏后的真实房源文案,覆盖整租、合租、押付与费用名目四种情况。

| 文件 | 场景 | 关注点 |
|---|---|---|
| `case-01.txt` | 北京望京整租一室一厅 | 服务费与押付,真实月成本 4988、首次支付 20250 |
| `case-02.txt` | 成都天府三街合租主卧 | 无中介费但收服务费与物业费 |
| `case-03.txt` | 深圳南山两室一厅 | 押二付一、中介费一个月、物业与网费另计 |
| `case-04.txt` | 上海徐汇一室户 | 免中介费但服务费顶到 620 元/月 |

`out/` 里是每份输入的完整输出,由离线模式生成,不调用模型,可逐字复现:

```bash
pip install -e .
python -m kanfang --mock scan --file examples/case-01.txt > examples/out/case-01.md
```

去掉 `--mock` 会走模型补语义矛盾与砍价话术,费用与矛盾仍由本地规则算。
